<locked_assumptions>
- D-03: eligible disordered pool = all episodes minus the **15 most recently watched** by `last_viewed_at` descending. Episodes with `last_viewed_at is None` are treated as never-watched and remain eligible.
- D-04: within a single rebuild, no series row emits the same episode `id` twice. Caller (builder) supplies `emitted_ids: set[str]`; picker filters and returns None when exhausted.
- D-05: if applying D-03 leaves the pool empty (e.g. series has 12 episodes total or every episode was watched in the past 15 unique slots), fall back to the **full episode list** for that row (still subject to D-04 emitted_ids).
- D-06: Episode DTO field `last_viewed_at: datetime | None = None` — UTC-aware datetime parsed from provider payload at mapper layer. Plex source: top-level `lastViewedAt` (unix seconds). Jellyfin source: `UserData.LastPlayedDate` (ISO 8601 string).
- D-08: when random pick hits ANY part of a multipart group, emit the FULL block via `expand_multipart_full_block` (04-02). One slot allocation → one full block.
- D-09: full-block expansion may include parts that were in the last-15 excluded set. Caller never needs to bypass D-03 explicitly; picker emits the entire block, then caller adds all block ids to `emitted_ids` (so subsequent disordered slots cannot re-pick any part).
- D-18: each rebuild produces fresh stochastic output (seed scoped to one build run; passed by Wave 3 builder).
- D-24: per-run seed (NOT frozen calendar day). Picker accepts a `random.Random` whose state is fully controlled by caller — picker never instantiates its own RNG.
- ROADMAP determinism criterion: same RNG state + same inputs MUST produce the same id sequence.
</locked_assumptions>

<out_of_scope>
- Slot allocation across multiple rows (Wave 3, plan 04-06)
- Plex/Jellyfin live HTTP calls (already mocked via existing client tests)
- Persistence of emitted_ids across rebuilds (D-16: fresh rebuild every time; emitted_ids never persisted)
- Hypothesis property tests (Wave 4, plan 04-07)
- Day-key derivation (D-24 supersedes — caller passes seed; tests use fixed seeds)
</out_of_scope>
