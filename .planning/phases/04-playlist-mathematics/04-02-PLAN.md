Create `backend/src/wheeloffish/core/playlist/multipart.py` exporting four pure functions. Module docstring must reference SCH-02, D-07, D-08, D-10, D-21.

Required signatures (do not deviate — Wave 2 pickers and Wave 3 builder import these names):

```
from collections.abc import Iterable
from wheeloffish.domain.dto import Episode

def group_by_multipart(episodes: Iterable[Episode]) -> dict[str, list[Episode]]: ...
def sort_multipart_block(parts: list[Episode]) -> list[Episode]: ...
def expand_multipart_full_block(anchor: Episode, episodes_by_id: dict[str, Episode]) -> list[Episode]: ...
def expand_multipart_forward(anchor: Episode, episodes_by_id: dict[str, Episode]) -> list[Episode]: ...
```

Implementation notes:
- `group_by_multipart`: skip episodes whose `multipart_group_id is None`. Build `defaultdict(list)`-style map; convert to plain `dict` at return.
- `sort_multipart_block`: sort key tuple is `(ep.part_index is None, ep.part_index or 0, ep.id)`. This gives ascending `part_index` with null sorting last and id-stable ordering for ties.
- `expand_multipart_full_block`: when `anchor.multipart_group_id is None` return `[anchor]`. Otherwise scan `episodes_by_id.values()` for matching `multipart_group_id`, sort via `sort_multipart_block`, return list. Anchor must appear in the result (caller relies on this) — if scanning omits the anchor (e.g. mismatched id key) explicitly include it then dedupe by `id`.
- `expand_multipart_forward`: when `anchor.multipart_group_id is None` return `[anchor]`. Otherwise build the full sorted block via `expand_multipart_full_block`, then if `anchor.part_index is None` return the full block (D-07 fallback), else slice from the first index where `part.part_index >= anchor.part_index`. The anchor itself MUST appear in the slice (no off-by-one). If anchor.part_index is set but no part with `part_index >= anchor.part_index` exists in the group, return `[anchor]` so callers always emit a non-empty block.

Do NOT add a SxxExx regex / heuristic fallback — D-21 says native field only in v1.
Do NOT import from `core/playlist/builder.py`, `ordered.py`, or `disordered.py` — those import from this module, not the other way around.

Append `__all__ = ["group_by_multipart", "sort_multipart_block", "expand_multipart_forward", "expand_multipart_full_block"]` for explicit re-exports.
