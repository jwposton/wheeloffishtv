  <behavior>
    - Builds `inputs_by_series: dict[str, SeriesRebuildInput]` from input list; missing series for a row → treat as empty episodes + no on_deck.
    - Phase 1: for each row in playlist.rows, call `evaluate_completion` then `apply_policy`; collect `row_outcomes`.
    - Active rows = outcomes where `excluded is False`.
    - Phase 2: `slot_assignments = allocate_slots([r.series_id for r in active rows matching outcomes], playlist.episode_count, playlist.slot_allocation, rng)`.
    - Phase 3: maintain `OrderedCursor` per ordered row (keyed by series_id); `emitted_ids: set[str]` per series for disordered.
    - For each slot_index, series_id assignment:
      - Lookup row + outcome; use `outcome.effective_mode`.
      - ORDERED: `block, cursor = next_block(...)`; update cursor dict.
      - DISORDERED: `pool = compute_eligible_pool(episodes)`; `block = pick_disordered_block(pool, by_id, emitted_ids, rng)`; add block ids to emitted_ids.
      - Empty block or None: do not increment slots_filled; continue to next slot.
      - Non-empty: append `BuiltEpisode(episode=ep, series_id=..., row_mode=effective_mode, slot_index=slot_index)` for each ep in block; increment slots_filled once per slot with output.
    - Return `PlaylistBuildResult(episodes=..., row_outcomes=..., day_key=rebuild_seed, slots_requested=playlist.episode_count, slots_filled=...)`.
    - RESTART policy: ordered picker receives restart flag from `outcome.policy_applied == CompletionPolicy.RESTART` via `start_index_for_row(..., restart=True)`.
  </behavior>
