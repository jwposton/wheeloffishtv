Create `core/provider_writeback.py`:

```python
@dataclass
class WritebackResult:
    status: Literal["succeeded", "partial", "failed", "skipped"]
    error: str | None
    warnings: list[dict]

async def push_snapshot(
    db, playlist: PlaylistOrm, run: RebuildRun, snapshot: list[dict], provider: MediaProvider,
) -> WritebackResult
```

Logic:
1. If connection provider is not `plex` (Jellyfin → return `skipped` until 07-02)
2. Resolve each snapshot `episode_id` → ratingKey; collect warnings for failures
3. If zero keys → `failed`, do not mutate provider playlist
4. If `playlist.provider_playlist_id` is None → create with display name + store id + set `provider_kind=plex`
5. Else → `replace_playlist_items`
6. Status `partial` if warnings and at least one key; `succeeded` if no warnings

Extend `MediaProvider` protocol with optional playlist methods OR use isinstance PlexProvider check in v1 (planner: prefer typed dispatch in provider_writeback, not fat protocol yet).

Hook `rebuild_playlist` **after** successful snapshot commit (status succeeded/partial):
- Call `push_snapshot`
- Set run.writeback_* fields + writeback_at
- db.commit() again
- Writeback exception → catch, set writeback_status=failed, do NOT change run.status or snapshot

Unit tests: mock PlexProvider/replace; orchestrator test asserts writeback fields set on partial mapping.
