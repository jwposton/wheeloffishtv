- `run_chunked_sync(connection_id, app_user_id)`:
  1. Load in_scope cached_libraries for connection (or fetch live libraries on first sync and default in_scope=true for env-scoped IDs)
  2. For each library: page through provider.list_series(page=N, limit=chunk_size) until empty
  3. Upsert cached_series rows with composite id, metadata, synced_at
  4. Update catalog_sync_state: page_cursor, total_estimated, status complete/failed
  5. Sleep 0.25s between chunks to avoid rate limits
- `get_sync_status(db, connection_id) -> dict` — status, progress_pct estimate
- On OAuth connect success (plans 03-04): call trigger_sync from callback handlers

Respect `WOF_SCOPED_LIBRARY_IDS` env if set — only those native_ids get in_scope=true on first library fetch.

No episode rows written to DB — series metadata only per D-14.
