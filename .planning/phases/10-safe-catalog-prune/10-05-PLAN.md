<objective>
Implement the documented cadence (D-05): each nightly run does a full catalog sync per connection BEFORE rebuilding that connection's due playlists. This lets a row reach the 3/3 threshold via the nightly sync + rebuild evidence channels rather than three separate operator logins. Refactor `run_nightly_batch` from "first-connection reachability + rebuild all" to a connection-grouped loop, awaiting `run_chunked_sync` directly (Pitfall 2/anti-pattern: never `asyncio.create_task` here).

Purpose: Satisfy D-05 ordering so sync-driven absence evidence (10-04) and rebuild-driven evidence (10-03) accumulate together each night, and unreachable connections reset counters (D-04) instead of drifting.
Output: Refactored `run_nightly_batch` in `orchestrator.py` + nightly ordering/reset tests in `test_orchestrator.py`.
</objective>
