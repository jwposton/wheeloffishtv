<objective>
Make rebuild a qualifying evidence channel (D-02). Replace the `SeriesRebuildInput | None` return of `fetch_rebuild_inputs_for_row` with a typed `FetchResult` so the orchestrator can distinguish a confident miss (`empty_snapshot`/`not_found`) from a transient `fetch_failure`. Gate all rebuild evidence behind `check_provider_reachable` (D-04), clear prune state for rows that fetch successfully (D-11), and trigger playlist-scoped auto-prune at the end of a successful/partial rebuild (D-06). Existing warning behavior in `row_outcomes_json` is preserved unchanged (D-07/PRUNE-04).

Purpose: A show deleted from Plex/Jellyfin returns `ProviderNotFound`; today that is mislabeled `fetch_failure` and never counts. This plan fixes the classification and accumulates rebuild evidence safely.
Output: `FetchResult` dataclass + ProviderNotFound branch in `rebuild_inputs.py`; reachable-gated evidence + auto-prune wiring in `orchestrator.py`; updated/added tests in `test_orchestrator.py`.
</objective>
