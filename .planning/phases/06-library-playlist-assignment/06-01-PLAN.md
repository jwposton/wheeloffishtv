## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01-01 | Tampering | plex/mappers.py `map_series` | mitigate | Coerce each enriched field through `str(...)` or `metadata.get(...)` with explicit None default; never trust raw dict access; clamp `genres` to `list[str]` via `[g.get("tag") for g in metadata.get("Genre", []) if isinstance(g, dict)]` to avoid TypeError on malformed payloads |
| T-06-01-02 | Information Disclosure | cached_series.provider_metadata JSON | accept | Metadata is per-user (CachedSeries scoped by app_user_id); existing _get_cached_series_in_scope (catalog.py) enforces library scope on read; no new endpoint exposes data cross-user |
| T-06-01-03 | Tampering | provider field with malformed type (e.g., `summary` as dict) | mitigate | Wrap each enriched read in defensive accessor that returns None when type unexpected; cited research pitfall 5 (assuming metadata always present) |
</threat_model>
