  <action>
Create `orchestrator.py`:

`async def rebuild_playlist(db, playlist_id: str, *, trigger: str) -> RebuildRun`:
1. Load Playlist ORM with rows; 404 if missing
2. Create RebuildRun status=running, started_at=now
3. Build provider via build_provider_for_user
4. For each row: fetch input; on None append row failure skip; on empty episodes mark empty_snapshot warning and skip row (D-14)
5. Call PlaylistBuilder.build(orm_to_playlist(orm), inputs, rebuild_seed=str(uuid4()))
6. Determine status: succeeded if all rows ok; partial if any skip/warning; failed if zero episodes emitted OR all rows excluded (D-12)
7. On succeeded/partial: serialize BuiltEpisode list to snapshot_json (episode id, title, series_id, slot_index, row_mode); store row_outcomes_json, slots_filled/requested, rebuild_seed
8. On failed: store error_message only; do NOT update last successful snapshot (D-17)
9. finished_at=now; commit
10. Call prune_rebuild_history(db, playlist_id, keep=3) deleting older rebuild_runs beyond 3 most recent with snapshot_json (D-16)

`async def run_nightly_rebuilds()`:
- Open db session
- If provider unreachable for first user connection: mark all due playlists failed with shared message (D-13) and return
- Query all playlists; filter is_due using now_in_tz(install_tz) from cadence module; sequential for loop calling rebuild_playlist (D-08)

`async def run_manual_rebuild(db, playlist_id, app_user_id)` — ownership check then rebuild_playlist

`def recover_interrupted_rebuilds(db)` — from 05-02 plan
