  <action>
Create SQLAlchemy models following existing Base + Mapped pattern:

`Playlist` table `playlists`:
- id String(36) PK (uuid4 string)
- app_user_id FK app_users.id CASCADE
- name String(256) not null
- episode_count Integer not null default 20
- slot_allocation String(32) not null default "wild"
- default_completion_policy String(32) not null default "remove"
- refresh_cadence String(16) not null default "daily" (D-04)
- refresh_day_of_week Integer nullable (0=Mon..6=Sun; null when daily per D-24)
- created_at, updated_at DateTime(timezone=True)
- relationship to rows and rebuild_runs with cascade delete-orphan

`PlaylistSeriesRow` table `playlist_series_rows`:
- id String(36) PK
- playlist_id FK playlists.id CASCADE
- series_id String(512) not null (matches cached_series.id composite string)
- mode String(16) default "ordered"
- completion_policy String(32) default "remove"
- completion_event String(32) default "series_complete"
- sort_order Integer not null default 0
- UniqueConstraint(playlist_id, series_id)

`RebuildRun` table `rebuild_runs`:
- id String(36) PK
- playlist_id FK playlists.id CASCADE
- status String(16) not null — values: queued, running, succeeded, failed, partial (D-09)
- error_message Text nullable
- rebuild_seed String(128) nullable
- slots_requested, slots_filled Integer nullable
- row_outcomes_json JSON nullable
- snapshot_json JSON nullable (D-15 full snapshot)
- started_at, finished_at DateTime(timezone=True)
- index on (playlist_id, started_at desc) for D-16 history queries

Export all three from db/models/__init__.py.
