## Phase Goal

**As a** self-host operator, **I want to** have playlists rebuild automatically on a nightly schedule in my household's timezone, **so that** fresh mixed-TV output aligns with when my family starts watching (SCH-01, D-01–D-05).

<objective>
Install APScheduler, wire install-timezone cron into FastAPI lifespan, implement cadence evaluation in local TZ, and recover interrupted jobs on startup.

Purpose: Time-based trigger layer before orchestrator rebuild logic.
Output: `scheduler.py`, `cadence.py`, modified `main.py` + `config.py`, unit tests.
</objective>
