<context>
## UAT gap (Test 1)

- **Truth:** View details when latest rebuild is partial/failed or writeback is partial/failed
- **Failed:** `status=succeeded`, `slots_filled=19`, `slots_requested=20`, no fetch_warnings → no trigger, empty banner guidance
- **Evidence:** `orchestrator.py` line 206: `partial if any_row_skipped else succeeded`; `shouldShowDiagnostics` ignores slot counts

## Approach

1. After `PlaylistBuilder.build`, derive unfilled slot indices (slot in `slot_assignments` with no `BuiltEpisode` at that `slot_index`).
2. Append `{"series_id": ..., "reason": "slot_unfilled"}` to `fetch_warnings` for each unfilled slot (dedupe by series if needed).
3. Set `run.status = "partial"` when `fetch_warnings` non-empty OR `slots_filled < slots_requested` (belt-and-suspenders).
4. Add `slot_unfilled` to `REASON_CATALOG` in resolver (D-18 known code).
5. Extend `shouldShowDiagnostics` to return true when `slots_filled != null && slots_requested != null && slots_filled < slots_requested`, OR when `last.diagnostics` has any row (defensive for API consumers).
</context>
