## Phase Goal

**As a** self-host operator, **I want to** manage watched state from a shared series detail page no matter where I enter it, **so that** playlist and Library flows stay in sync with provider watch progress.

<objective>
Complete shared series detail watch-state experience, including grouped season display, status affordances, and provider-backed watch actions.

Purpose: Deliver end-user parity goal for Phase 09 by composing backend API routes from Plan 09-02 with frontend parity wiring from Plan 09-03.

</objective>

## Grey Area Decisions (Locked)

- **UI reconcile strategy (B=3)**:
  - Episode actions: optimistic update + rollback on error
  - Season/series actions: no optimistic update; invalidate/refetch after mutation response
- **Back navigation (C=2)**:
  - Best-effort return to origin (Library / view-playlist / edit-playlist)
  - Fallback to Library when origin context is missing/invalid
